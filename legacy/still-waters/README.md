# Still Waters demo (retired design)

The first demo, a fictional "Still Waters Apparel" store with a hero, cards, badges, a dark mode and a simulated Stripe checkout. Replaced by the plain Qivgu store in the repository root, but kept here in case any of its CSS or cart code is wanted again. `index.html` is the artifact-style source (no doctype); the standalone page is served at `/old/` on the demo site (`docs/old/index.html`). Nothing here is loaded by the live store.
