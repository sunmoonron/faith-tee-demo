# Still Waters Apparel — demo store

A working front-end demo of a print-to-order t-shirt store for a Christian apparel brand: pre-order drop, shipping and local pickup, cart, promo code (FAITH10), HST, and a simulated hand-off to Stripe Checkout. No payments are taken; everything runs in the browser.

- `index.html` — the page source (published as a Claude artifact, which wraps it in a document skeleton)
- `build.sh` — wraps `index.html` into `docs/index.html`, a standalone page served by GitHub Pages
